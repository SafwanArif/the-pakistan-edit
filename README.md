# The Pakistan Edit (Content Engine v2027)

Institutional headless content generation engine designed for ultra-modern, high-fidelity news production.

## Architecture
- **Framework**: Next.js 15 (App Router)
- **UI**: React 19 + OKLCH Design Tokens
- **AI**: Gemini 1.5 Flash (Narrative Ingestion)
- **Persistence**: Client-side LocalStorage (Zero-gravity architecture)
- **Export**: Institutional Multi-Platform Rendering (IG / TT / FB)

## Getting Started

```bash
npm install
npm run dev
```

## Maintenance & Integrity
- All brand assets are located in `public/assets/logos`.
- Editorial templates use standard OMNI_CONFIG for cross-platform alignment.
- Image processing is handled via the internal Asset Proxy to safeguard CORS and fidelity.
